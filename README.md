# ملاعب العراق — حجز تذاكر ثلاثي الأبعاد

تسعة ملاعب: المدينة الدولي (الحبيبية)، البصرة الدولي، الشعب، كربلاء، النجف، الميناء الأولمبي، فرانسو حريري، ميسان الأولمبي، الزوراء.

تطبيق ويب تجريبي مبني بـ Three.js و Vite. Developed by Yasser Omar.

## التشغيل

```bash
npm install
npm run dev        # ثم افتح العنوان الذي يظهر (عادة http://localhost:5173)
npm run build      # نسخة الإنتاج داخل dist/
npm test           # اختبارات منطق المقاعد والحجز (بدون متصفح)
```

بدون تثبيت: الملف `index.cdn.html` يحمّل Three.js من الإنترنت. شغّل أي خادم ملفات داخل المجلد
(مثلاً `npx serve` أو `python -m http.server`) وافتح `index.cdn.html`.

```
src/main.js           التطبيق: المشهد، الكاميرات الثلاث، الربط
src/stadium/layout.js نموذج المدرجات والمقاعد (حساب بحت، بدون Three.js)

src/stadium/seats.js  المقاعد والجمهور والأعلام (InstancedMesh) واختيار المقعد
src/stadium/pitch.js  أرضية الملعب، المرميان، دكّة البدلاء، لوحات LED
src/stadium/match.js  22 لاعباً وحكم وكرة متحركة
src/stadium/textures.js  خامات مرسومة بالكود (لا توجد صور)
src/camera/controls.js   الدوران، التقريب، اللمس، الطيران بين المشاهد
src/booking/store.js  السلة، الرسوم، الحجوزات، LocalStorage

```

## إضافة ملعب أو مباراة أو تغيير الأسعار

كل شيء في `src/config.js`:
- ملعب جديد: أضف عنصراً إلى `VENUES` (أبعاد المدرج، عدد الصفوف، ألوان المقاعد، نوع السقف والواجهة، مع مبارياته في `fixtures`). النموذج ثلاثي الأبعاد يتولد من هذه الأرقام.
- الأسعار في `CATEGORIES` والرسوم في `FEES`.

ملعب المدينة مبني من صور حقيقية. بقية الملاعب: السعة وشكل المدرج (كروي أو بمضمار) قريبة من الواقع، أما ألوان المقاعد والواجهات والسقوف فتقديرية.

## المباريات

قائمة المباريات القادمة (`MATCHES` في `src/config.js`) لقطة مأخوذة يوم 14 تشرين الثاني 2026: الجولات 14 إلى 18 من دوري نجوم العراق ومباريات المنتخب. الصفحة لا تجلب بيانات حية، فحدّث القائمة يدوياً عند تغيّر الجدول. `HOME_VENUE` يحدد ملعب كل نادٍ؛ النوادي غير الموجودة فيه تظهر مبارياتها بدون حجز.

## ملاحظات

- عرض تجريبي: لا يوجد دفع حقيقي ولا تُجمع أي بيانات بطاقة. الحجوزات تُحفظ في متصفحك فقط.
- رمز QR على التذكرة زخرفي وغير قابل للمسح.

## الحجز المشترك (Supabase)

الحجوزات صارت محفوظة بقاعدة بيانات Supabase (المشروع: iraq-football-tickets):
- المقعد اللي يحجزه أي شخص يصير "مباع" عند الكل، ويتحدث مباشرة بدون تحديث الصفحة.
- إذا شخصين حجزوا نفس المقعد بنفس اللحظة، واحد بس ينجح، والثاني تطلعله رسالة ويختار غيره.
- معلومات المشتري (الاسم، الإيميل، الموبايل) محفوظة بالقاعدة ومحد يگدر يقراها من الموقع.
- الإعدادات بملف `src/config.js` تحت `SUPABASE`. إذا تمسح الرابط، الموقع يرجع يشتغل تجريبي على الجهاز فقط.
- الدفع بعده تجريبي.

## حسابات المشجعين

- الحجز يحتاج تسجيل دخول بالإيميل وكلمة المرور، وكل مشجع يشوف تذاكره من أي جهاز.
- كل مشجع يگدر يحجز 4 مقاعد كحد أقصى بالمباراة الوحدة.
- الحساب الجديد لازم يتأكد من رسالة توصل على الإيميل.
